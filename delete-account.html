정식 출시 전 확정 예정

1. 계정은 만들지 않아요

현재 사진게임에는 회원가입·로그인·서버 계정이 없습니다. 별도의 계정 탈퇴 없이 기기에서 사진과 게임 데이터를 직접 삭제할 수 있습니다. 개발자가 보관하는 앱 계정이나 업로드 사진은 없습니다.

2. 사진 한 장 또는 사진팩 삭제

  1. 앱 하단의 사진팩 → 내 사진팩 관리에서 대상 사진팩을 엽니다.
  2. 사진을 누른 뒤 앱에서 사진 삭제를 선택하거나, 사진팩 화면의 사진팩 삭제를 선택합니다.
  3. 삭제 내용을 확인합니다. 앱 내부의 사진 복사본이 삭제되며 휴대폰 사진첩의 원본은 유지됩니다.

3. 게임 기록 초기화

홈의 설정 → 게임 기록 초기화 → 기록 삭제를 선택합니다. 이 작업은 기록과 기록 배지만 지웁니다. 열린 레벨·별·사진팩은 남아 있습니다. 모든 진행을 지우려면 아래 전체 삭제 방법을 사용하세요.

4. 앱 데이터 전체 삭제

  1. Android 설정 → 앱 → 사진게임 → 저장공간으로 이동합니다.
  2. 데이터 삭제 또는 저장공간 삭제를 선택하고 확인합니다. 또는 앱을 제거합니다. 제조사에 따라 메뉴 이름이 다를 수 있습니다.
  3. 앱 안의 사진 복사본, 사진팩 이름, 레벨·별·기록, 혼자 하기·함께 하기·친구 도전 상태, 참가자 이름과 설정이 삭제됩니다.
캐시 삭제만으로는 전체 데이터가 지워지지 않습니다.

앱에 클라우드 백업이나 복원 기능이 없으므로 전체 삭제 후 진행을 복구할 수 없습니다.

5. 별도로 지워야 하는 정보

휴대폰 사진첩 원본, 다른 앱에 저장한 결과 카드, 친구에게 보낸 도전 코드와 메시지는 앱 데이터 삭제로 지워지지 않습니다. 해당 사진첩·파일·공유 앱에서 직접 관리하세요. 이미 수신자에게 전달한 파일이나 메시지는 수신자가 보관할 수 있습니다.

6. 문의 정보의 삭제 요청

운영자에게 이메일로 보낸 문의 정보의 삭제는 greatryuhg@gmail.com로 요청하세요. 제목에 ‘사진게임 문의 정보 삭제’를 적고, 이전 문의를 보낸 이메일과 대략적인 날짜를 알려주세요. 비밀번호·개인 사진·신분증은 보내지 마세요.

문의 기록 정책: 문의 기록의 보유 기간과 삭제 절차는 확정 후 안내합니다.
요청 처리 안내: 요청 처리 기한은 확정 후 안내합니다.

홈페이지는 기기 안의 데이터를 대신 삭제하지 않습니다. 고객지원에서 이메일 초안을 작성할 수 있으며 직접 전송해야 요청이 전달됩니다.
