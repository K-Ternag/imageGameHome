1. 계정 없이 이용하는 앱

리멤픽 자체 계정이나 온라인 프로필이 없어 별도 회원 탈퇴는 필요하지 않습니다. 아래에서 기기 데이터, 외부 공유, Google Play 구매, 문의 기록을 나누어 안내합니다.

2. 사진·사진팩 삭제

  1. 사진팩에서 내 사진팩을 엽니다.
  2. 사진을 눌러 앱에서 사진 삭제를 선택하거나 사진팩 삭제로 팩 전체를 삭제합니다.
  3. 앱 내부 복사본만 삭제되며 갤러리의 원본은 남습니다.

3. 게임 기록 초기화

홈 → 설정 → 게임 기록 초기화 → 기록 삭제를 선택하세요. 기록과 기록 배지만 삭제합니다. 열린 레벨·별·사진팩은 남습니다. 모든 진행을 지우려면 다음 절차를 이용하세요.

4. 앱 전체 데이터 삭제

  1. Android의 설정 → 앱 → 리멤픽 → 저장공간을 엽니다.
  2. 데이터 삭제 / 저장공간 비우기를 확인하거나 앱을 제거합니다. 기기별 메뉴 이름은 다를 수 있습니다.
  3. 사진 복사본·사진팩·레벨·별·기록·함께 하기 이름·설정·로컬 구매 상태·이벤트 기록이 삭제됩니다.
캐시 삭제만으로 모든 데이터가 지워지지는 않습니다.

사진팩·게임 기록의 백업 기능이 없어 전체 삭제 후 진행을 복원할 수 없습니다. 갤러리 원본은 별도로 보관해 주세요.

5. 원본·외부 공유·광고 정보

갤러리 원본과 저장·공유한 결과 카드는 앱 데이터 삭제 후에도 남을 수 있습니다. 갤러리·파일 관리자·공유 서비스에서 별도로 관리하세요. 수신자가 받은 파일도 자동 삭제되지 않습니다.

광고 개인정보 선택은 앱 설정에 해당 항목이 제공되면 변경할 수 있습니다. Google 등 외부 제공자의 처리 기록은 앱 삭제와 별개이며 제공자 정책과 문의 경로를 이용하세요.

6. 구매 기록·복원·환불

앱 삭제는 Google Play 구매 내역을 삭제하거나 결제를 환불하지 않습니다. 광고 제거 구매는 같은 Google 계정으로 설정 → 광고 없이 즐기기 → 구매 복원에서 복원할 수 있습니다. 사진팩·게임 기록은 복원되지 않습니다.

거래 정보와 환불은 Google Play 환불 안내와 구매 내역에서 확인하거나 greatryuhg@gmail.com로 문의하세요.

7. 문의 기록 삭제 요청

greatryuhg@gmail.com로 제목에 리멤픽 문의 정보 삭제 요청을 적어 보내 주세요. 기존 문의에 사용한 이메일과 대략적인 문의 날짜만 알려주시면 됩니다. 비밀번호·신분증·개인 사진은 보내지 마세요.

문의 처리 완료 후 30일 동안 보관합니다. 기간이 끝나거나 확인된 삭제 요청을 처리할 때 운영자가 문의 이메일과 첨부를 메일함·휴지통에서 영구 삭제하고 별도로 저장한 첨부 사본도 삭제합니다. 메일 제공자의 시스템 기록·백업은 해당 제공자의 정책을 따릅니다.
