1. 적용 범위와 운영자

리멤픽 / RememPic Android 앱과 이 소개 홈페이지의 개인정보 처리 안내입니다. 운영자는 K-Terang이며 개인정보 문의는 greatryuhg@gmail.com로 접수합니다. 확인한 앱 버전은 0.9.0입니다. 앱 자체 회원가입·로그인과 개발자 백엔드는 없습니다. 기기 안의 사진·게임 데이터와 광고·구매·홈페이지·이메일의 외부 처리를 구분합니다.

3. 사진 접근과 권한

Android 사진 선택기로 직접 고른 사진만 읽습니다. 전체 갤러리·위치·연락처·마이크·카메라 권한을 요구하지 않습니다. 사진은 방향을 반영한 뒤 긴 변 최대 1,200px의 JPEG로 앱 안에 복사하며 GPS·EXIF 정보는 복사본에 보존하지 않습니다. 원본은 변경하지 않습니다. 사진의 색·구도 분석도 기기에서 수행합니다.

인터넷·네트워크 상태 권한은 광고와 구매 확인에 사용합니다. 개인 사진·게임 기록·참가자 이름을 개발자 서버 또는 광고 요청에 넣어 전송하지 않습니다.

4. 광고와 개인정보 선택

게임 사이에 Google AdMob 전면 광고를 제공할 수 있습니다. Google Mobile Ads SDK는 IP 주소(대략적 위치 추정 가능), 앱 실행·탭·광고 반응, 성능·진단 정보와 설정에 따른 기기 식별정보를 광고 제공·측정·부정 이용 방지 목적으로 처리할 수 있습니다. 광고 ID 접근 권한을 제거했더라도 모든 광고 데이터 처리가 없어지는 것은 아닙니다. Google 광고 SDK 데이터 안내를 확인할 수 있습니다.

앱은 광고 동의 상태가 광고 요청을 허용하는지 확인한 뒤 광고를 준비합니다. 제공되는 경우 설정의 광고 개인정보 설정에서 선택을 변경할 수 있습니다. 광고 제거 구매가 확인되면 게임 사이 광고를 중단하지만 구매 확인에 필요한 처리는 계속될 수 있습니다.

5. 아동과 보호자

앱은 나이·생년월일·회원 계정을 요청하지 않습니다. 아동용 광고 설정이 적용된 빌드에서는 Google의 CHILD 처리를 사용해 개인 맞춤 광고·리마케팅·광고 ID 전송을 제한하도록 구성하고 광고 콘텐츠 등급을 G로 제한합니다.

보호자는 아동의 사진 선택·외부 공유·Google Play 구매를 함께 관리해 주세요. 보호자는 아래 이메일로 문의 정보의 열람·삭제 등을 요청할 수 있습니다. 아동의 개인 사진·신분증·민감한 정보는 문의에 첨부하지 마세요.

6. Google Play 구매

광고 제거는 Google Play의 1회 구매 상품입니다. 앱은 상품 ID, 구매 토큰, 상태와 서명된 구매 정보를 이용해 결제 확인·승인·복원을 수행하고 마지막 확인 상태를 기기에 저장합니다. 개발자는 카드번호·은행 계좌정보·Google 비밀번호를 직접 수집하지 않습니다. 기기 이벤트 기록에는 구매 토큰·영수증·이메일·사진 경로를 넣지 않습니다.

Google Play가 처리하는 결제·거래 기록은 Google 정책에 따르며 앱 제거로 삭제되지 않습니다. Google 개인정보처리방침을 참고하세요.

7. 공유와 외부 처리

결과 카드와 앱 소개를 공유하면 사용자가 고른 외부 앱과 수신자가 해당 이미지·메시지를 처리합니다. 결과 카드에 개인 사진은 포함하지 않습니다. 앱에는 사진·기록의 클라우드 동기화나 별도의 개발자 분석·원격 오류 수집 서비스가 없습니다. 광고 SDK의 측정·진단 처리는 4항과 같이 별도로 이루어집니다.

8. 보관 기간과 파기

기기 사진·설정·기록은 이용자가 삭제할 때까지 보관합니다. 사진이나 사진팩 삭제는 앱 내부 복사본을 지웁니다. 게임 기록 초기화는 기록·기록 배지만 지우며 열린 레벨·별·사진팩은 남깁니다. 전체 기기 데이터는 Android 앱 데이터 삭제 또는 앱 제거로 삭제합니다. 광고·결제 이벤트는 최근 80개까지 유지하며 오래된 항목은 새 기록으로 대체합니다.

문의 기록: 문의 처리 완료 후 30일 동안 보관합니다. 기간이 끝나거나 확인된 삭제 요청을 처리할 때 운영자가 문의 이메일과 첨부를 메일함·휴지통에서 영구 삭제하고 별도로 저장한 첨부 사본도 삭제합니다. 메일 제공자의 시스템 기록·백업은 해당 제공자의 정책을 따릅니다.

Google·GitHub가 관리하는 거래·보안·접속 기록과 백업은 각 제공자의 목적별 보관·삭제 정책이 적용됩니다. 모든 외부 기록에 동일한 보관일수를 적용하지 않습니다. 데이터 삭제 안내에서 범위별 절차를 확인하세요.

9. 이용자 권리와 요청

이용자와 보호자는 기기 사진·사진팩을 직접 관리하고 운영자에게 보낸 정보의 열람·정정·삭제·처리 정지를 greatryuhg@gmail.com로 요청할 수 있습니다. 요청 범위 확인에 필요한 최소한의 확인만 진행하며 처리 제한이 있으면 사유를 안내합니다. 접수 후 요청 내용을 확인하여 지체 없이 답변하며, 추가 확인이나 시간이 필요한 경우 사유와 예상 일정을 안내합니다.

개발자는 이용자 기기에만 있는 데이터에 원격 접근하거나 대신 삭제할 수 없습니다. Google 계정·구매 관련 정보는 해당 서비스의 개인정보 설정과 문의 경로로도 관리할 수 있습니다.

10. 보호 조치

개인 사진과 게임 데이터는 Android 앱 전용 저장소에 보관하고 Android 자동 백업은 비활성화합니다. 공유 파일 접근은 사용자가 선택한 대상에 허용합니다. 문의 내용은 대응과 권리 행사에 필요한 범위에서만 사용하며 보관기간 후 운영자가 삭제합니다. 이용자는 기기 잠금과 외부 공유 파일 관리를 설정할 수 있습니다.

11. 홈페이지·이메일·국외 처리

홈페이지에는 자체 분석·광고 스크립트, 추적 쿠키, 외부 웹폰트, 회원가입·사진 업로드가 없습니다. GitHub Pages는 방문자의 IP 주소와 접속 요청 등 기술 정보를 호스팅·보안 목적으로 처리합니다. 문의 작성기는 이메일 앱에 초안을 열 뿐 홈페이지 서버에 내용을 접수하거나 저장하지 않습니다. 직접 전송한 이메일은 Gmail 등 이메일 제공자와 운영자가 처리합니다.

광고·Google Play·Gmail은 Google, 홈페이지 호스팅은 GitHub가 제공하며 서비스 과정에서 미국을 포함한 다른 국가에서 정보가 처리될 수 있습니다. 구체적 처리 위치와 보관·삭제 조건은 Google 개인정보처리방침, Google 보관·삭제 안내, GitHub 개인정보처리방침을 따릅니다. 개발자는 개별 이용자의 외부 저장 위치나 일률적인 보관기간을 지정하지 않습니다.
