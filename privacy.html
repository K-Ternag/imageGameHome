1. 적용 범위

이 방침은 사진게임 Android 앱과 소개 홈페이지에 적용됩니다. 현재 확인한 앱 버전은 0.8.0입니다. 앱은 회원가입·로그인·개발자 서버를 사용하지 않습니다. 아래에서 기기 안의 데이터 처리와 홈페이지·문의 과정의 처리를 구분하여 설명합니다.

2. 처리하는 정보와 이용 목적

정보목적 및 저장 위치
직접 선택한 사진·사진팩 이름·표지 설정사진 게임과 사진팩 관리. 앱 전용 저장소에 보관합니다.
게임 기록·점수·레벨·별·진행 중 상태·설정게임 이어하기와 결과 표시, 사용 환경 유지. 기기에 저장합니다.
함께 하기 참가자 이름·점수·진행 상태차례 안내와 결과 비교. 해당 기기에 저장하며 영구 온라인 프로필을 만들지 않습니다.
친구 도전 코드·문제 재현 정보·목표 및 도전 점수동일한 문제를 재현하고 결과 비교. 기기에 저장하며 사용자가 직접 공유합니다.
문의 이메일·문의 내용·직접 첨부한 정보사용자가 이메일로 보낸 경우에만 문의 대응에 이용합니다. 메일 서비스 및 운영자가 처리합니다.

3. 사진 접근과 기기 권한

Android 시스템 사진 선택기로 사용자가 선택한 사진만 읽습니다. 전체 사진첩, 위치, 연락처, 마이크, 카메라 접근 권한을 요구하지 않습니다. 선택한 사진은 방향을 반영한 후 긴 변 최대 1,200px의 JPEG로 앱 내부에 복사하며, 복사본의 GPS·EXIF 메타데이터를 제거합니다. 원본 사진은 변경하지 않습니다. 사진의 색·구도 분석도 기기 안에서 수행합니다.

현재 앱은 인터넷 권한을 선언하지 않으며 개인 사진이나 게임 기록을 개발자 서버로 전송하지 않습니다. 개인 사진에는 얼굴 등 식별 가능한 내용이 있을 수 있으므로 본인에게 사용 권한이 있는 사진을 선택해 주세요.

4. 외부 제공·공유·광고

현재 앱에는 광고, 결제, 분석, 원격 오류 수집 SDK가 포함되어 있지 않으며 앱 데이터를 판매하거나 광고 목적으로 제공하지 않습니다. 외부 인증·클라우드 동기화 서비스도 사용하지 않습니다.

사용자가 결과 카드 또는 친구 도전 코드를 공유하면 선택한 외부 앱과 수신자가 해당 내용을 처리합니다. 결과 이미지에는 개인 사진이 포함되지 않습니다. 친구 도전 코드는 기본 사진과 문제 재현 정보·점수를 포함하며 서버에 조회하지 않습니다. 외부 공유 앱의 처리는 해당 서비스의 방침에 따릅니다.

5. 보유 기간과 삭제

기기 내 사진·설정·진행·기록은 사용자가 삭제하거나 앱 데이터를 지울 때까지 해당 기기에 보관합니다. 개인 사진 또는 사진팩 삭제 시 앱 내부의 해당 사진 복사본을 삭제합니다. 게임 기록 초기화는 기록과 기록 배지만 삭제하고 열린 레벨·별·사진팩은 유지합니다. 모든 로컬 데이터는 Android 설정의 앱 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다. 서버 백업이나 앱의 클라우드 복원 기능은 제공하지 않습니다.

함께 하기 진행·결과는 다음 진행으로 교체하거나 해당 모드를 종료하는 동작에 따라 삭제됩니다. 모든 상태를 지우려면 앱 데이터를 삭제하세요. 사진첩 원본과 외부에 공유·저장한 파일은 별도로 관리해야 합니다.

문의 기록 보유·삭제 정책: 문의 기록의 보유 기간과 삭제 절차는 확정 후 안내합니다.

자세한 절차는 데이터 삭제 안내를 확인하세요.

6. 이용자와 보호자의 권리

이용자는 앱에서 개인 사진을 확인·삭제하고, Android 설정에서 앱 전체 데이터를 삭제할 수 있습니다. 운영자에게 보낸 문의 정보의 열람·정정·삭제·처리 정지는 아래 연락처로 요청할 수 있습니다. 요청 처리에 필요한 최소한의 본인 확인을 요청할 수 있습니다. 개발자는 이용자 기기에만 있는 사진·게임 기록에 원격 접근하거나 이를 대신 삭제할 수 없습니다.

보호자는 아동이 사용하는 기기의 사진 선택과 공유를 함께 관리할 수 있고, 관련 문의를 같은 연락처로 보낼 수 있습니다. 앱은 계정·나이·생년월일을 요청하지 않습니다. 아동의 개인 사진이나 민감한 정보를 문의에 첨부하지 마세요.

7. 보호 조치

개인 사진 복사본과 게임 데이터는 Android 앱 전용 저장소에 보관합니다. 앱의 Android 자동 백업은 비활성화되어 있습니다. 공유 기능은 사용자가 선택한 공유 대상에 필요한 파일 접근을 허용합니다. 홈페이지에는 사진 업로드나 회원가입 기능이 없으며, 기기의 화면 잠금 및 외부 공유 파일 관리는 이용자가 설정할 수 있습니다.

8. 홈페이지와 이메일 문의

이 홈페이지는 자체 방문자 분석·광고 스크립트, 추적 쿠키 및 외부 웹폰트를 사용하지 않습니다. GitHub Pages 호스팅 과정에서 IP 주소·접속 요청 등 기술 정보가 GitHub에 의해 처리될 수 있으며, 처리 위치·기간·권리 행사 방법은 GitHub 개인정보처리방침에 따릅니다.

문의 작성 기능은 이용자의 이메일 앱에서 초안을 여는 기능입니다. 작성 내용은 이 홈페이지의 서버에 접수·저장되지 않습니다. 이용자가 직접 이메일을 전송한 뒤에는 메일 서비스와 운영자가 처리합니다. 외부 서비스 이용 시 해당 서비스의 처리 국가와 방침을 함께 확인하세요.
